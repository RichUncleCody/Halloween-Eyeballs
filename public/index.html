Keeping the screens awake

  • The page asks the browser for a screen wake lock. Browsers only allow that on https:// pages or on http://localhost.
  • Loading from another machine over plain http? Use the https link (the server makes its own certificate: click Advanced → Proceed once per machine). Or turn off display sleep in the OS.
  • Press D on a screen to see whether keep-awake is active.

Kiosk mode (no browser chrome)

Chrome / Edge: chrome --kiosk --autoplay-policy=no-user-gesture-required /L

Extras for each screen URL: ?size=0.9 eye size, ?gap=0.05 bezel gap between monitors, ?q=0.7 render quality.
